## Template Usage Rules

1. **Templates are frameworks, not final messages** — always personalize
2. **Never send a template as-is** — add specific observations
3. **Match template to prospect type** — use the right framework
4. **Get human approval** — always, for every message
5. **Keep it human** — if it sounds like a template, rewrite it
