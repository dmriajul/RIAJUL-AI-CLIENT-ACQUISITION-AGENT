# Daily Client Acquisition Workflow

## Trigger Command
```
Run today's client acquisition workflow
```

---

## Step-by-Step Process

**Output:**

```
  CONTACTED: [X]

  FOLLOW-UP 2: [X]

  MEETING: [X]
  PROPOSAL: [X]
  WON: [X]
  LOST: [X]

```

---

### Step 2: Follow-Up Identification
**Action:** Identify all follow-ups due today.

**Output:**
```
FOLLOW-UPS DUE TODAY
━━━━━━━━━━━━━━━━━━━

2. [Company] — Follow-Up #[N]
   Channel: [Email/LinkedIn]
   Last contact: [Date]
   Reason: [Reason]
   Draft: [Follow-up message draft]

Total follow-ups due: [X]
```

---

### Step 3: New Prospect Research
**Action:** Research new prospects based on ICP.

**Target:** 10-20 new prospects per day (adjustable)

**Process:**
1. Identify target industry/geography for today
2. Search for companies matching ICP criteria
3. Research each company (website, social media, ads, content)
4. Identify decision makers
5. Document findings in CRM format

**Output:**
```
NEW PROSPECTS RESEARCHED
━━━━━━━━━━━━━━━━━━━━━━━

1. [Company] — [Industry]
   Website: [URL]
   Size: [Size]
   Country: [Country]
   Key observation: [One-line observation]
   Priority: [A/B/C]

2. [Company] — [Industry]
   ...

Total new prospects: [X]
```

---

### Step 4: Qualification
**Action:** Qualify all researched prospects.

**Process:**
1. Review research notes for each prospect
2. Apply ICP criteria
3. Assign A/B/C priority with reasoning
4. Identify best opportunities

**Output:**
```
QUALIFICATION RESULTS
━━━━━━━━━━━━━━━━━━━━

Strong Fit (A): [X] prospects
  1. [Company] — Reason: [Brief reason]
  2. [Company] — Reason: [Brief reason]

Potential Fit (B): [X] prospects
  1. [Company] — Reason: [Brief reason]

Weak Fit (C): [X] prospects (not recommended for outreach)

Top opportunities:
  1. [Company] — [Service] — [Why]
  2. [Company] — [Service] — [Why]
  3. [Company] — [Service] — [Why]
```

---

### Step 5: Opportunity Prioritization
**Action:** Identify highest-value opportunities to pursue today.

**Priority order:**
1. A-fit prospects with clear opportunities
2. B-fit prospects with strong signals
3. Follow-ups that need attention
4. Replies that need responses

**Output:**
```
TODAY'S PRIORITIES
━━━━━━━━━━━━━━━━

High Priority:
  1. [Company] — [Action needed] — [Why priority]
  2. [Company] — [Action needed] — [Why priority]

Medium Priority:
  3. [Company] — [Action needed]
  4. [Company] — [Action needed]

Lower Priority:
  5. [Company] — [Action needed]
```

---

### Step 6: Outreach Drafting
**Action:** Create personalized outreach messages for priority prospects.

**Process:**
1. For each priority prospect, draft outreach message
2. Apply personalization framework (Level 3)
3. Include relevant proof
4. Follow email/LinkedIn rules
5. Present for approval

**Output:**
```
OUTREACH DRAFTS (AWAITING APPROVAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. [Company] — [Channel: Email/LinkedIn]
   Contact: [Name] — [Role]
   
   Subject: [Subject line]
   
   Message:
   ---
   [Full outreach message]
   ---
   
   Personalization basis: [What observations this is based on]
   Relevant proof: [What proof this references]
   
   [ ] APPROVED  [ ] REVISE  [ ] SKIP

2. [Company] — [Channel: Email/LinkedIn]
   ...
```

---

### Step 7: CRM Update
**Action:** Update all prospect records with today's activities.

**Process:**
1. Update statuses for all touched prospects
2. Record dates for all outreach sent
3. Set next follow-up dates
4. Update next actions
5. Add notes where relevant

---

## Workflow Customization

### Adjust daily targets:
```
Find 15 new prospects today
```

### Focus on specific industry:
```
Focus today's research on ecommerce fashion brands in the USA
```

### Focus on specific service:
```
Today, focus on Meta Ads opportunities only
```

### Skip research, focus on follow-ups:
```
Skip research today, focus on all pending follow-ups
```
